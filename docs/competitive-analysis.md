# 유사 서비스 비교와 보완점

조사일: 2026-10-25. 공개 기사·앱 스토어 설명·규제기관 발표를 기준으로 했습니다. 업체가 내부 운영 방식을 거의 공개하지 않아서, 출처가 엇갈리거나 2025년 이전 자료만 있는 항목은 ⚠로 표시했습니다.

## 서비스별 현황

| 서비스 | 매칭 조건 | 유해 콘텐츠 대응 | 연령·신원 | 참여 기능 | 수익 모델 |
| --- | --- | --- | --- | --- | --- |
| **우리 프로젝트** | 언어 + 관심사 3개(10초 완화). 성별·지역 없음 | 사용자 신고, 서로 다른 3명 신고 시 1시간 제한, IP별 요청 제한. 자동 판별 없음 | 없음(익명 게스트) | 채팅, 다음 상대, 끊김 후 재개. 한국어 웹만 | 없음 |
| **Azar** (하이퍼커넥트, Match Group) | 관심사 무료, 성별·국가는 유료 | AI + 사람 검토, 유해 영상 감지 시 화면을 가리는 Video Blur, 24시간 대응 | 18+, 사진·영상 셀피 연령 확인 ⚠, 장기 성실 이용자 배지 | 실시간 자막 번역, 프로필, 팔로우, 상호 동의 연결 | 젬(인앱 결제) + 프리미엄 |
| **OmeTV** | 국가·성별 ⚠ | 자동 제재 ⚠, 신고 | 18+ 체크박스 | 스와이프 넘기기, 채팅 | 광고·인앱 ⚠ |
| **Chatroulette** | 무작위 | AI 나체 감지(2020–21 도입 ⚠), 신고 | 18+. 계정·얼굴 확인 여부는 출처마다 다름 ⚠ | 기본 기능 | 광고, 가상화폐 ⚠ |
| **Monkey** | 짧은 시간제 통화, 연장 | 이미지 인식 업체 2곳 + 24시간 검토(자사 주장) | 연령 확인 없음 | 시간 연장, 스냅챗 교환 | 인앱 ⚠ |
| **Emerald Chat** | 관심사 무료, 성별·평판은 Gold, 국가·언어는 Platinum | 평판(karma) 점수, 신고 | 연령 확인 없음 | 친구, 그룹 채팅, 텍스트 모드 | 구독 |
| **Uhmegle** (Omegle 계열) | 관심사, 텍스트/영상 | AI + 사람(자사 주장, 미검증) | 로그인·연령 확인 없음 | 텍스트 모드 | 광고 ⚠ |

**Omegle**은 2023-11-08에 문을 닫았습니다. 11세에 성인과 연결돼 피해를 입은 이용자의 소송(*A.M. v. Omegle*)과 합의한 직후였습니다. 이 소송에서 법원은 "**만나서는 안 될 사람을 연결하는 매칭 설계 자체**"를 제조물 결함으로 다툴 수 있다고 보고, 통신품위법 230조 면책을 적용하지 않았습니다([NPR](https://www.npr.org/2023/11/09/1211807851/omegle-shut-down-leif-k-brooks), [Bloomberg Law](https://news.bloomberglaw.com/corporate-governance/techs-online-content-shield-dented-by-product-liability-claims)).
**OmeTV**는 미성년자 보호 조치가 부족하다는 이유로 호주 eSafety에서 2025-08 공식 경고를 받았고, 2025-10에는 호주 앱 스토어에서 내려갔습니다([eSafety](https://esafety.gov.au/newsroom/media-releases/luck-runs-out-for-roulette-style-video-chat-app-placing-australian-children-at-risk)).
Azar 수치와 기능은 [Byline Network(2025-12)](https://byline.network/2025/12/11-570/), [Google Cloud 사례](https://cloud.google.com/customers/hyperconnect) ⚠, 미국 앱 스토어 설명을 참고했습니다.

## 규제 — 이 분야에서 운영자가 지는 의무

- **한국 (가장 직접적)**: 여성가족부는 2020-09-10 고시(2020-12-11 시행)로, 불특정 이용자를 연결하는 랜덤채팅 서비스에 다음 세 가지 중 하나라도 없으면 **청소년유해매체물**로 지정했습니다.
  1. 실명·휴대폰 본인인증
  2. 대화 내용 저장
  3. 신고 기능

  지정되면 19세 이용 불가 표시와 성인인증 의무가 생기고, 어기면 형사처벌 대상입니다. 당시 점검한 408개 앱 중 154개가 운영을 중단했고, 12개 사업자가 형사고발됐습니다([뉴시스 2020-12-10](https://mobile.newsis.com/view/NISX20201210_0001266032), [더나은미래](https://futurechosun.com/archives/54180)).
  성평등가족부 누리집의 청소년유해매체물 목록에는 이 고시가 2020-09-10 날짜로 그대로 올라 있고, 개정 근거는 찾지 못했습니다([목록](https://www.mogef.go.kr/sp/yth/sp_yth_s001.do?mid=gnr111)).
  - **우리 프로젝트에 대입하면**: 신고 기능은 있지만, 본인인증이 없고 대화 저장도 신고할 때만 합니다. 그래서 그대로 국내에 공개 운영하면 지정 대상으로 봐야 합니다.
- **영국 Online Safety Act**: 불법 유해물 의무가 2025-03-17부터 적용됐습니다(위험 평가, 신고 도구, 그루밍 방지 기본값). 아동 보호 의무는 "매우 효과적인 연령 확인"을 요구합니다. 2026년에는 채팅 사이트를 상대로 조사가 시작됐습니다([Digital Policy Alert](https://digitalpolicyalert.org/event/43033-office-of-communications-expanded-investigation-into-provider-of-teen-chat-to-cover-information-notice-compliance-and-reporting-of-child-sexual-exploitation-and-abuse-content)).
- **EU DSA 28조**: 2025-07 미성년자 보호 가이드라인에서 위험이 높은 서비스에는 연령 *검증*을 권고했습니다. 약관에 적어 두는 것만으로는 부족하다고 봅니다([Taylor Wessing](https://www.taylorwessing.com/en/insights-and-events/insights/2025/07/rd-european-commission-guidelines-on-protection-of-minors-under-the-digital-services-act)).
- **공통 흐름**: 이용자가 직접 입력한 나이를 믿는 방식으로는 부족하다는 쪽으로 규제가 모이고 있습니다. 신고를 받는 데서 끝내지 않고, 증거 보관과 사람의 검토, 미성년자와 성인의 접촉 방지까지 요구합니다.

## 보완점 (우선순위)

안전과 법적 요건을 먼저 두고, 참여 기능은 뒤로 미뤘습니다. "포트폴리오에서 구현 가능"은 외부 계약이나 실명 데이터 없이 이 저장소 안에서 할 수 있는지를 뜻합니다.

| 순위 | 보완점 | 경쟁 서비스 | 포트폴리오에서 구현 가능 |
| --- | --- | --- | --- |
| 1 | **연령 확인 단계**: 시작 전 이용 연령·이용수칙 동의, 본인인증 연동 지점(어댑터) | Azar 셀피 연령 확인, OmeTV 18+ 확인 | 동의 화면과 인증 어댑터 구조는 가능. 실제 본인인증은 PASS 등 계약 필요 |
| 2 | **영상 가리기**: 연결 직후 상대 영상을 흐리게 두고, 사용자가 직접 걷어 내기 | Azar Video Blur | 가능(클라이언트) |
| 3 | **신고 검토 절차**: 처리 상태, 검토자, 이의 제기, 신고 증거 보관 기한 | Azar 사람 검토 | 가능(admin 확장, 보관 기한 정리 명령) |
| 4 | **IP보다 오래가는 제재 단위**: 계정 기반 제재, 로그인 사용자 우선 정책 | Azar·Chatroulette 계정 기반 | 부분 가능(계정 제재). 기기 식별은 개인정보 이슈 |
| 5 | **이용약관·개인정보 처리방침·안전 수칙 페이지** | 대부분 게시 | 가능 |
| 6 | **자동 유해 영상 판별** | Azar, Chatroulette(Hive) | 브라우저 내 판별 모델은 가능하지만 정확도·성능 검증 부담이 큼 |
| 7 | **신뢰 지표**: 신고 없이 오래 이용한 사용자 우선 | Azar 배지, Emerald karma | 가능(계정 이력 기반) |
| 8 | **참여 기능**: 화면 다국어화, 실시간 번역, 상호 동의 친구 추가, 성별·지역 필터 | Azar, Emerald | 다국어화·친구 추가는 가능. 번역은 외부 API 필요 |

**이번 점검에서 이미 반영한 것**(2026-10-25)
- 3번 일부: 신고 대화 보관 기한(90일)과 삭제 명령, 신고 남발 제한, 관리자 로그인 제한
- 개인정보: 상대에게 공인 IP를 숨기는 TURN 전용 옵션, 가명 처리 고지

**이어서 반영한 것**(2026-10-25, [안전 장치](trust-and-safety.md))
- 1번: 매칭 전 연령·수칙 동의(서버 강제, 약관 버전 관리)와 본인인증 어댑터·강제 옵션. 실제 인증기관 연동은 계약이 필요해 남겨 둠
- 2번: 연결 직후 상대 영상 흐림(사용자가 직접 걷어 냄)
- 3번: 신고 검토 상태, 인정 시 7일 제재, 기각 시 자동 제한 해제, 계정 없이 가능한 이의 제기
- 4번: 인증된 사람 단위 제재(인증을 켰을 때)
- 5번: 이용약관·개인정보 처리방침·안전 수칙 페이지(초안), 계정 직접 삭제
- 8번 일부: 대화 화면 영어 지원([i18n](i18n.md))
- 남은 것: 6번 자동 유해 영상 판별, 7번 신뢰 지표, 8번 실시간 번역·친구 추가

### 제안 순서

1. **이용수칙·연령 동의 화면 + 약관·개인정보 처리방침·안전 수칙 페이지**(1, 5번): 작업이 작고, 국내 고시의 "청소년 이용 제한" 요건을 화면에서 보여 줄 수 있습니다.
2. **연결 직후 상대 영상 흐림**(2번): 클라이언트만 고치면 되고, 원치 않는 노출을 바로 줄이는 효과가 큽니다.
3. **신고 검토 절차**(3번): 처리 상태, 검토자, 조치, 이의 제기를 둡니다. 자동 제재를 사람이 확정하거나 취소할 수 있게 합니다.
4. **본인인증 어댑터**(1, 4번): 인증 결과(성인 여부, 중복가입 확인값)만 받는 인터페이스와 테스트용 가짜 구현을 만듭니다. 실제 업체 연동은 계약 후에 붙입니다.
5. 화면 다국어화, 상호 동의 친구 추가, 신뢰 지표(6–8번)

### 우리 프로젝트가 이미 앞선 부분

- **끊김 복구**: 통화 중 신호·미디어가 끊겨도 같은 상대와 이어집니다(20/20). 조사한 서비스 중 이를 공개적으로 내세운 곳은 없었습니다.
- **측정 가능한 운영**: 통화 성공률, TURN 경유 비율, 복구 결과, 대기 시간 분포를 지표로 공개하고 대시보드와 경보로 묶었습니다.
- **조작할 수 없는 신고 근거**: 서버가 직접 중계한 대화만 저장합니다. 경쟁 서비스의 증거 처리 방식은 공개되지 않았습니다.
- **무료 선호 매칭**: 경쟁 서비스 대부분은 필터를 유료로 팝니다. 우리는 공통 관심사 매칭을 기본 기능으로 제공하고, 그 대가(대기 시간)를 측정해 공개했습니다.
