## 새 스냅샷 검사

- 가상환경, node_modules, SQLite/DB, .env 및 환경별 .env 파일, 개인 키, 테스트 결과, 로그, 정적 빌드 결과는 추적 대상에서 제외했습니다.
- 새 파일 스냅샷의 개인 키/일반적인 GitHub 토큰/AWS 키 시그니처와 2 MB 초과 파일을 검사했습니다. 검출 없음.
- 테스트에 사용하는 TURN 비밀 문자열과 환경변수 예시는 테스트/개발용 값입니다. 실제 TURN 공유 비밀키는 환경변수에서만 읽습니다.
- 패턴 검사만으로 모든 종류의 비밀정보 부재를 보장하지는 않습니다. 업로드 대상 파일 목록과 애플리케이션 설정도 함께 검토했습니다.

이번 변경은 해당 파일과 키를 최신 스냅샷에서 제거합니다. 기존 원격에 없는 민감 파일을 새로 추가하지 않습니다. 그러나 **이전 커밋을 조회하면 여전히 접근할 수 있습니다.** 같은 저장소의 이미 존재하는 공통 조상 이력은 그대로 유지됩니다.

실제 사용한 자격증명이 있다면 재사용하지 말고 교체해야 합니다. 과거 DB까지 제거하려면 별도의 이력 정리와 GitHub 캐시/노출 대응 절차가 필요합니다. 이번 작업에서는 이력 보존 및 force push 금지 조건에 따라 수행하지 않았습니다.
