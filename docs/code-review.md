## 리뷰어가 문제없다고 확인한 부분

- 클라이언트는 상대의 신원, IP 해시, 채널 이름을 받지 않습니다. 메시지 대상은 서버가 정하고, 양쪽 match_id가 일치해야 전달됩니다.
- 재개 토큰은 144비트이고, 서버가 만들며, 1회용입니다. 대화를 나가면 폐기되고, 예전 소켓이 늦게 끊겨도 영향이 없습니다.
- XSS 방어: 신뢰할 수 없는 텍스트는 모두 `textContent`로만 넣고, admin은 `format_html_join`으로 이스케이프합니다(테스트 있음).
- CSRF와 Origin 검사, 로그아웃 POST 전용, 지표 토큰의 상수 시간 비교.
- 고정 윈도 제한의 원자성, 마지막 프록시 홉만 신뢰하는 `X-Forwarded-For` 처리.
